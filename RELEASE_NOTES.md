# Release Notes

## v1.0 — Portfolio Release

This release packages the Smart Student Attendance Management System as a public portfolio project.

### Included
- Student management
- QR generation and scanning
- Attendance check-in/check-out
- Attendance history
- Dashboard analytics
- Student attendance reports
- Academic calendar support
- Safe local database configuration

### Before running
- Use Java 23
- Install and start MySQL
- Run the supplied database schema
- Create `config/db.properties` locally from the example file
- Create a local admin account using `database/create_admin.sql`

No real credentials or private local configuration are included.
